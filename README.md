One line of software error copy that tells the user the brutal truth about what went wrong — and makes them laugh on the way.

> Error 500: the server is down because someone deployed on a Friday. That someone was us. Try again Monday.

The program writes the line to `/output/entry.txt` (1–200 code points, single line, valid UTF-8). Built for the make.fun bounty "Say What Actually Broke".
